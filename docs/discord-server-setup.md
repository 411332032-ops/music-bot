# Discord 伺服器設定指南（Windows）

這份文件帶你一步一步做三件事：

1. 建立一個**你自己的** Discord 伺服器
2. 建立給 agent 用的**專用頻道**，並拿到它的 `CHANNEL_ID`
3. 產生**邀請連結**，讓同組同學加入

做完之後，接著看 [`docs/discord-bot-setup.md`](discord-bot-setup.md) 建立機器人。

> **名詞先講一下**
> - **伺服器（Server）**：Discord 裡的一個「社群空間」，像一棟大樓。
> - **頻道（Channel）**：伺服器裡的「房間」。文字頻道就是聊天室。
> - **CHANNEL_ID**：每個頻道都有一個專屬的長數字編號。程式靠這個編號知道「只聽哪一個房間」。
>
> **關於畫面文字**：Discord 常常改版，畫面上的中文字可能和我寫的略有不同。我會在括號裡附英文原文，對不上時以英文對照。以下都是在 **Windows 版 Discord 桌面程式**操作。

---

## 事前準備

- [ ] 電腦已安裝並登入 Discord 桌面程式（沒有的話到 https://discord.com/download 下載「Windows」版）。
- [ ] 準備好一個記事本，等一下要記下 `CHANNEL_ID`。

---

## 第一部分：建立你自己的 Discord 伺服器

1. 打開 **Discord**。
2. 看畫面**最左邊**那一長條，由上往下是你的伺服器圖示。拉到最下面，找到一個**綠色的「＋」**（滑鼠移上去會顯示「新增伺服器」，Add a Server）。**點它**。
3. 跳出視窗後，點最上面的 **「親自創建」**（Create My Own）。
4. 下一個畫面問「這個伺服器是為了誰？」，點 **「供我和我的朋友使用」**（For me and my friends）。
5. 在 **「伺服器名稱」**（Server Name）欄位輸入名稱，例如 `音樂辨識實驗室`。
   - 上傳伺服器圖示是選用的，可以跳過。
6. 點右下角的 **「建立」**（Create）。
7. 你會自動進到新伺服器，左邊最上面會多出它的圖示，**你就是這個伺服器的擁有者**。

**確認**：左側欄位看得到你剛建的伺服器，點進去有一個預設的文字頻道（通常叫 `一般`，General）。

---

## 第二部分：建立專用頻道

目的：只讓 agent 聽「這一個頻道」。其他頻道的圖片不會被處理，也不會花你的 Claude 額度。

### 2-1 建立頻道

1. 在你的伺服器裡，看**左邊第二條**（頻道清單）。找到分類名稱 **「文字頻道」**（Text Channels）。
2. 把滑鼠移到「文字頻道」這幾個字上，右邊會出現一個 **「＋」**。**點它**。
   - 找不到的話：在頻道清單空白處**按滑鼠右鍵**，選 **「建立頻道」**（Create Channel）。
3. 在「頻道類型」，選 **「文字」**（Text）。
4. 在「頻道名稱」輸入：`音樂封面與歌詞辨識`
   - Discord 可能會自動把空格換成 `-`，這是正常的，不影響使用。
5. **「私人頻道」**（Private Channel）的開關先**保持關閉**。
   - 開了的話，同學要另外被你加進這個頻道才看得到，現階段不需要。
6. 點右下角 **「建立頻道」**（Create Channel）。

**確認**：頻道清單的「文字頻道」底下多了 `#音樂封面與歌詞辨識`。

### 2-2 打開「開發者模式」

預設情況下 Discord 不會顯示頻道編號，要先打開開發者模式。

1. 看 Discord 視窗**左下角**，會看到你的頭像和名字，旁邊有一個**齒輪圖示**（使用者設定，User Settings）。**點它**。
2. 在左邊清單往下找，到 **「應用程式設定」**（App Settings）這一組，點 **「進階」**（Advanced）。
3. 右邊找到 **「開發者模式」**（Developer Mode），把開關**打開**（變成綠色）。
4. 按右上角的 **「ESC」** 圈圈（或鍵盤按 `Esc`）回到主畫面。

### 2-3 複製 CHANNEL_ID

1. 在頻道清單裡，對 `#音樂封面與歌詞辨識` 按**滑鼠右鍵**。
2. 在選單最底下附近，點 **「複製頻道 ID」**（Copy Channel ID）。
   - 看不到這一項的話，表示開發者模式沒打開，回到 2-2。
3. 打開**記事本**，按 `Ctrl + V` 貼上。你會看到一串 17～19 位數的數字，例如：

   ```
   123456789012345678
   ```

4. 在這串數字前面加上名稱，記成這樣（之後要放進 `.env`）：

   ```
   CHANNEL_ID=123456789012345678
   ```

> **提醒**：CHANNEL_ID 不是密碼，但也不需要公開。**不要和 `DISCORD_TOKEN` 搞混**，token 才是絕對不能外流的東西（見 [`discord-bot-setup.md`](discord-bot-setup.md)）。

## 第三部分：產生邀請連結，讓同學加入

### 3-1 先想清楚一件事

這個伺服器之後會讓同學**一起測試、也會做攻防練習**。而且：

> **頻道裡的每一個人，傳的每一張圖，都會花你自己的 Claude 額度。**

所以邀請連結只給**你信任的同組同學**，並且設定**到期時間**和**使用次數**。

### 3-2 產生連結

1. 在頻道清單裡，對 `#音樂封面與歌詞辨識` 按**滑鼠右鍵**。
2. 點 **「邀請別人」**（Invite People）。
   - 或：點伺服器名稱（左上角）→ **「邀請朋友」**（Invite People）。
3. 跳出視窗，下方會顯示一條連結，像 `https://discord.gg/xxxxxxx`。**先不要急著複製**，先做設定。
4. 點視窗**右下角**的**齒輪圖示**（編輯邀請連結，Edit invite link）。
5. 設定兩項：
   - **「到期時間」**（Expire After）：選 **「7 天」**（7 days）。需要更短就選「1 天」。**不要選「永不」**（Never）。
   - **「最大使用次數」**（Max Number of Uses）：填你同組人數再多一點，例如 `10`。
6. 點 **「產生新連結」**（Generate a New Link）。
7. 點連結旁邊的 **「複製」**（Copy）。

### 3-3 傳給同學

1. 用 LINE、Messenger 或其他你們平常聯絡的方式，把連結傳給同組同學。
2. 請同學：
   - 點連結 → 如果出現「在 Discord 中開啟」，選開啟。
   - 按 **「接受邀請」**（Accept Invite）。
   - 加入後，在 `#音樂封面與歌詞辨識` 頻道就看得到你們的聊天。

### 3-4 請同學遵守的規則

傳給同學時，可以一併附上：

- 這個頻道的圖片會被 AI 分析，並保存在管理者（我）的電腦上，**不要傳身分證、帳單、私人照片**。
- **不要一次連傳很多張**。一個人同時排隊最多 5 張。
- 做安全測試（攻防）時，只在這個伺服器的這個頻道做，不要拿去攻擊別的地方。

### 3-5 如果連結外流了怎麼辦

1. 點伺服器名稱（左上角）→ **「伺服器設定」**（Server Settings）。
2. 左邊清單往下找到 **「邀請」**（Invites），點進去。
3. 找到那條連結，點右邊的 **「✕」**（撤銷）。
4. 需要的話，回 3-2 再產生一條新的。
